# Cookie clicker PS3

Port of the [Cookie clicker](https://orteil.dashnet.org/cookieclicker/) game to the PlayStation 3, using [psl1ght](https://github.com/ps3dev/ps3dev) and [tiny3d library](https://github.com/wargio/tiny3D)

Alpha 2 is now released! Available on [GitHub releases](https://github.com/IvanPashaev/Cookie-Clicker-PS3/releases/latest/), [AcidPS3-Store](https://github.com/AcidPS3-Project/AcidPS3-Store) and [PS3 WORLD](https://ps3.world/ports#cookie-clicker)

## Build

build pkg:
```bash
make pkg
```

build elf:
```bash
make
```
